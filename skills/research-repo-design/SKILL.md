# Research Repository Design

Start with the smallest runnable experiment. A script plus its inputs and saved outputs is sufficient when it supports the claim. Preserve seed, config, relevant package versions, and raw evidence regardless of layout.

Use `references/research_experiment_repo.md` for incremental structure choices. Do not introduce a package, fixed directory tree, Makefile, or configuration framework solely because this is a research repository.
