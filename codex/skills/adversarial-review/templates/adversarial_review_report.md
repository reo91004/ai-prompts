# Review

State the supported result and the current claim decision first.

- Required Fixes: concrete errors or unsupported claims, with evidence and a remedy
- Research-Sufficient: findings supported within the stated scope
- Optional Hardening: useful extensions that do not block this result
- Do Not Change: evidence or simplicity that should be preserved

Omit empty categories. For a negative or inconclusive result, give the plausible causes, useful discriminating checks, and next action. Keep hypotheses separate from established findings.
